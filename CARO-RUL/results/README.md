# Generated experiment results

Historical benchmark metrics, per-run predictions, validation traces, trained checkpoints and figure/table output directories are **not included** in this release. Experiments will write under `results/` and `outputs/`; those paths are ignored by Git to avoid inadvertently committing large or incomplete outputs.

The repository **does include** the SW1--SW7 processed input data. Re-run the documented experiments to obtain numerical results. `scripts/revision/build_revision_tables.py` expects upstream experiment-result directories, including B019/B020 artifacts, that are not pre-bundled here. Do not claim the revised manuscript's exact numerical tables are independently reproducible from the existing ZIP without generating or supplying these prerequisites.
